## 9929 是什么，凭什么比 4837 贵一档

AS9929 是中国联通的精品网骨干，业内直接叫“联通 9929”。它的价值体现在回程：电信用户从机房回国的数据走 AS9929 到上海电信，联通用户直连 AS9929 到上海联通，移动方向则走 AS9808，也就是 Cmin2。三家运营商各有各的优质链路，晚高峰不太容易出现某一家单独卡死的情况。

在丽萨自己的产品体系里，9929 处在 4837 和 CN2 GIA 之间。4837 是联通 A 网，价格更低、带宽更大，同门还有不限流量版本；CN2 GIA 在电信方向回程质量更极致，价格也明显更高。9929 的位置是“比 4837 稳一点、比 GIA 便宜”。

第三方评测（老刘博客）对一期精简版的实测数据可以做参考：电信平均 175ms、联通 171ms、移动 176ms，洛杉矶本地 6ms；去程从南京、深圳、济南出发，都是各自骨干网到上海或圣何塞出境，接 Cogentco 到洛杉矶，没有绕日本或欧洲。这个延迟水平对建站、远程办公、代理中转都够用。

## 年付四档：每多花 100 块换到什么

**199 和 299 的差别只有两处：IP 属性和流量。** 199 元那台是“非美国原生 IP”，10G SSD、200GB 月流量；299 元那台是美国原生 IP，硬盘同样是 SSD，流量翻到 400GB。多 100 元买的是 IP 归属地，不是性能。对 TikTok、ChatGPT 这类查归属地的服务，非原生 IP 是个实打实的风险点；纯建站或代理，199 元那台够用。非原生版还有一条补救路径：每月加 20 元可以换美国原生 IP，年付用户能免费换一次。

**299 到 499 这 200 元，换的东西最多。** 从美国原生 IP 升级成双 ISP 家宽住宅 IP，硬盘从 SSD 换成 NVMe，流量从 400GB 加到 600GB。住宅 IP 的意义在于 IP 数据库把它判定为家庭宽带而不是机房段，老刘博客对精简版的评测里，IPinfo、ipregistry、ipapi、AbuseIPDB 四个库都判为 Residential，Netflix、Disney+、YouTube Premium、Amazon Prime Video、Spotify、ChatGPT 全部通过。如果你做的事会被平台查 IP 类型，这 200 元是整条产品线上花得最值的一笔。

**德国那台 499 元没有和别人重叠。** 法兰克福机房，原生 IPv4 + 原生 IPv6 双栈，10G NVMe，50Mbps 带宽，600GB 月流量。它和多花 200 块买双 ISP 是两条路线：一个换 IP 类型，一个换 IP 地域。欧洲 IP 在部分 AI 服务的风控上比美国 IP 宽松，双栈对纯 IPv6 环境兼容更好，官方把它定位成“AI 全家桶”。但它不是美国线路，做美区业务的人用不上。

预算试水的话，年付四档从低到高就一句话：先确定你要不要住宅 IP，要就跳过前两档，不要就按流量选 199 或 299。

## 几个必须先知道的限制

**部分 IP 段禁 ping。** 官方产品页写得很直白：“应 IP 提供方要求，此产品部分 IP 段禁了 ping，不能 ping 是正常的，不影响使用。”所以拿 ping 测延迟测不通不代表机器坏了，第三方评测也是用官方测试 IP 测的延迟，实际 IP 禁 ping。下单前建议向商家索取测试方式，公开资料里没有稳定的测试地址可查。

**50Mbps 是这批套餐的天花板之一。** 年付四档里三档都是 50Mbps，一期精简版也是 50Mbps，只有基础版 60Mbps、进阶版 80Mbps、豪华版 100Mbps。跑大流量下载或高并发业务，这个带宽会成为瓶颈，不是 IP 的问题。

**最高配置只有 4 核 4G。** 丽萨卖的是 IP 资源和线路，不是算力。要跑重负载应用、编译、大内存服务，这家不在你的选择范围内，直接找高性能独服更省事。

**退款有例外，但德国 9929 双栈不在例外里。** 全系 48 小时不满意无条件退款、自动开通即时交付。标注“特殊产品，仅退网站余额”的是几款住宅 VDS（美国家宽 VDS、日本 IIJ、德国双 ISP 住宅 VDS、日本 ISP 静态住宅等），它们只退到网站余额，不退原支付账户。德国 9929 双栈双原生（499 元/年那台）和德国双 ISP 住宅 VDS 是两款不同产品，退款条款不一样，别搞混。

**套餐命名容易买错。** 同一家店把 9929 拆成“年付特价”“一期”“二期”“德国双栈”四组，同名套餐跨组重复，1 核 1G 的价格从 199 元/年拉到 1288 元/月。下单前确认清楚买的是哪一组、哪种 IP 属性、什么计费周期，这三项错一个，买回来的东西就不是你要的。

**非原生 IP 有归属地风险。** 199 元那台写明是非美国原生 IP，IP 段可能不在美国本土，对查归属地的平台不友好。多花 100 元上 299 元原生版能规避这个问题，这也是年付档里最容易被忽略的一次升级。

## 常见疑问

**9929 和 4837 怎么选？**
9929 高峰期更稳，价格贵一档；4837 起价更低、带宽更大，同门还有不限流量版本（美国 4837 双 ISP 住宅年付 399 元/年、100Mbps、600GB 月流量）。对峰值延迟敏感选 9929，对带宽和流量敏感选 4837。

**能拿来建站吗？**
可以。1 核 1G 跑轻量站点和博客没问题，NVMe 的 4K 小文件读写 209.79 MB/s 对数据库响应有帮助。流量大的站点建议直接从 88 元基础版或 158 元进阶版起步。
